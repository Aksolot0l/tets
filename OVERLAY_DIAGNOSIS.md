# Диагностика оверлея

Проверена DLL из репозитория с SHA-256
`f74a42c4aedd1c9d1f0c92200e9c7e977d800ab686d108114b2711c0c81835c5`.
Это статический анализ, без запуска в Windows или Minecraft.

- В DLL есть функции `PresentHook` и `Present1Hook`, но их наличие само по себе
  не подключает их к DirectX. `DllMain` в этой сборке только возвращает успех;
  прямых вызовов `MH_Initialize`, `MH_CreateHook` и `MH_EnableHook` из кода
  запуска при просмотре дизассемблирования не обнаружено.
- В этой DLL обе функции `PresentHook` / `Present1Hook` вызывают отрисовку,
  после чего возвращают `S_OK`, не вызывая оригинальный `Present`. Вручную
  подключать их в таком виде опасно: игра может перестать показывать кадры.
- В присланном фрагменте `injected.cpp` `InputState::Update` вызывается шесть
  раз за кадр, что может сбрасывать события нажатия. Кроме того, в нём нет
  установки хуков и вызова `ImGui_ImplDX11_Init` перед `NewFrame`.

Проверка выполнялась с помощью `objdump -t`, `objdump -d` и `objdump -p`.
Внешний код теоретически может вызывать экспортированные функции DLL, поэтому
вывод об отсутствии подключения внутри DLL не доказывает поведение всей системы.
В репозитории нет полного проекта, а среда проверки не поддерживает Windows;
поэтому исправленную и проверенную DLL предоставить пока нельзя. Изменение
права доступа через скрипты само по себе не добавит недостающий код запуска.
