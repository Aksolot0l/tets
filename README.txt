# GAYClient Internal 0.3.5-mouse-test

В репозитории находятся готовые Windows x64 client.exe и GAYClientInternal.dll,
а также скрипты настройки прав. Исходного кода оверлея здесь нет.

В описании прежней сборки указано: отключён курсор ImGui, используется ввод
CoreWindow, внизу оверлея отображается строка «UWP mouse test...» с диагностикой.
Эти свойства и работоспособность текущих бинарных файлов не проверены.

ВАЖНО: контрольная сумма находящейся в репозитории DLL не совпадает ни с
SHA256SUMS.txt, ни с указанной в прежнем README (95a1f85c39c7650729b9b5189a2231e20772ff05ffdd80c755119d529bc8491c).
Фактическая сумма на момент проверки:
f74a42c4aedd1c9d1f0c92200e9c7e977d800ab686d108114b2711c0c81835c5
Проверьте DLL командой Windows `certutil -hashfile GAYClientInternal.dll SHA256`
и сверяйте результат с доверенным источником сборки. Не запускайте неизвестный
бинарный файл до проверки. SHA256SUMS.txt сохранён как исходный документ, а не
обновлён под непроверенную DLL.

Права доступа (только если DLL получена из доверенного источника):
- ENABLE_ACCESS.cmd сначала сохраняет текущий DACL этой машины в
  DACL_BACKUP.local.txt, затем выдаёт ALL APPLICATION PACKAGES право чтения и
  выполнения DLL. Это изменение безопасности; оно не гарантирует работу оверлея.
- RESTORE_ACCESS.cmd восстанавливает локальную копию DACL из того же каталога.
  После проверки восстановления сохраните или удалите локальную копию вручную
  перед повторным запуском ENABLE_ACCESS.cmd. Скрипты сообщают об ошибках.
- Прилагаемый DACL_BACKUP.txt относится к другой системе и не должен
  использоваться как резервная копия прав на вашем компьютере.

Скрипты изменены по документации icacls, но не проверены на Windows в этой среде.


Экспериментальное восстановление находится в папке repair: см. repair/README.md.
Адаптер собран, но не проверен в Windows и Minecraft; работоспособность не
гарантирована. Он не заменяет автоматически исходную DLL в корне проекта.


Установка и обновление с GitHub:
- INSTALL_FROM_GITHUB.ps1 скачивает экспериментальную сборку из ветки
  arena/5d11f1ec-tets. По умолчанию установка — в D:\GAYClient-Repair.
- Закройте Minecraft и клиент. Сохраните установщик и выполните в PowerShell:
  powershell -NoProfile -ExecutionPolicy Bypass -File "путь\INSTALL_FROM_GITHUB.ps1"
  Для другой папки добавьте `-Destination "D:\путь\к\папке"`. Родительская
  папка должна существовать. При повторном запуске установщик обновляет только
  файлы известных версий и не удаляет остальные пользовательские файлы.
- После подтверждения установщик сохраняет ACL двух DLL в локальные файлы и
  предоставляет ALL APPLICATION PACKAGES чтение и выполнение. Существующие
  резервные копии сохраняются. RESTORE_ACCESS.cmd возвращает исходные права.
- Для обновлений используется манифест из той же ветки GitHub, что и файлы.
  Проверка хешей выявляет несовпадение файлов с манифестом, но не подтверждает
  происхождение или безопасность загруженного содержимого.
- Установщик обновлён, но его установка и обновление не проверены на Windows.
