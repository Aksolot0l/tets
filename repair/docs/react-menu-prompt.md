# Промпт: веб-реплика внутриигрового меню GAYClient на React

> Скопируй всё, что ниже черты, и отдай другой ИИ.

---

Сделай **автономное веб-приложение на React** — пиксельно точную реплику внутриигрового меню игрового клиента «GAYClient» (стиль веб-лаунчера: тёмная тема, ярко-зелёный акцент). Это демо-стенд интерфейса, без бэкенда: всё состояние локальное (useState/zustand на твой выбор).

## Стек

- React 18 + TypeScript, Vite, один Page, CSS-модули или обычный CSS (переменные в `:root`), без UI-библиотек — вся стилизация вручную по спецификации ниже.
- Допустимо: framer-motion не нужен — переходы чистым CSS `transition`.

## Общий вид

- Фон страницы: тёмная «игровая» подложка — radial-gradient `#0d1410` → `#060a08`, лёгкий эффект шума не нужен.
- Окно меню **shell** центрировано, размер `1140×716px`, НО клампится к вьюпорту: `width: min(1140px, 100vw - 24px); height: min(716px, 100vh - 24px)` (позиционирование через flex-центрирование родителя).
- Скругление окна `18px`, фон `#0a100d` с прозрачностью 97% (`rgba(10,16,13,0.97)`), рамка `1px rgba(58,232,130,0.26)`, лёгкая внешняя тень (чёрная, 40%).
- Шрифт: `"Segoe UI", system-ui, sans-serif`. Базовый размер 20px.
- Анимации появления: окно fades-in + scale 0.98→1 за 0.15s.

## Поведение и критерии приёмки

1. Вкладки переключаются кликом по nav-рейлу; активная подсвечена (фон + бар + точка).
2. Секции сворачиваются/разворачиваются с поворотом стрелки; состояние сохраняется при переключении вкладок.
3. Тумблеры: клик — кноб уезжает/возвращается с анимацией 0.16s, цвета по спеке.
4. Слайдеры: перетаскивание обновляет значение живьём; цветовой чип «Скорость радуги» перекрашивается по RGB-слайдерам секции.
5. Состояние модулей общее между вкладками «Модули» и «HUD»; слайдеры катаны/короны общие между «Графика» и «Test tools».
6. Окно зажимается к вьюпорту (не вылезает за края при маленьком экране), контент-область скроллится со стилизованным скроллбаром.
7. Кнопка × закрывает меню (показать оверлей «открыть заново»), «Настроить HUD» — toast.
8. Test tools перетаскивается и не выходит за пределы вьюпорта.
9. Никаких внешних картинок и иконок-библиотек: чипы — текстовые символы (эмодзи/юникод).
10. Сборка: `npm install && npm run dev` поднимает приложение без правок; TypeScript без any в публичном коде.

Сгенерируй полный проект: файловая структура, все компоненты, стор, CSS. Не сокращай код комментариями «...» — всё должно компилироваться и работать сразу.
