# Промпт v2: веб-GUI внутриигрового меню GAYClient — красота уровня лаунчера

> Скопируй всё, что ниже черты, и отдай ИИ. Это НЕ лаунчер и НЕ игра — отдельный
> красивый веб-стенд интерфейса настроек (вкладки, ползунки, тумблеры FPS/CPS и
> т.д.). С EXE/DLL ничего делать не нужно.

---

Сделай **автономное веб-приложение** — роскошную веб-версию внутриигрового меню
игрового клиента GAYClient (Minecraft Bedrock). Это витрина GUI: тёмное стекло,
зелёное свечение, аврора-фон — визуальный уровень современного игрового
лаунчера. Бэкенда нет: всё состояние локально + localStorage.

## Стек (обязательно)

- **React 19 + TypeScript + Vite** (как в реальном проекте).
- **Tailwind CSS v4** (`@import "tailwindcss"` + `@theme`) + один файл
  `index.css` с дизайн-системой на CSS-переменных.
- **lucide-react** для иконок, **@fontsource/manrope** (400–800),
  **@fontsource/russo-one**, **@fontsource/press-start-2p** (все шрифты локально).
- Состояние: `useState`/`useReducer` + кастомный хук `usePersistedState`
  (JSON в localStorage, ключ `gayclient.menu.v1`). Никаких Redux/MobX.
- Запуск: `npm install && npm run dev` — работает сразу, без правок.

## Поведение

1. Горячие клавиши: `1–4` — вкладки, `Esc` — закрыть меню (экран возврата),
   `Ctrl+Enter` — toast «Настройки применены».
2. Всё состояние (тумблеры, слайдеры, свёрнутость секций, тема, вкладка,
   позиция Test tools) сохраняется в localStorage и восстанавливается.
3. Тосты: стек снизу-центра, `toast-in`, авто-скрытие 4.5s, иконка по тону
   (success/info/warning/error), закрытие по клику.
4. FPS в шапке считается честно через requestAnimationFrame (скользящее
   среднее за ~0.5с), при `visibilitychange` — пауза.
5. `prefers-reduced-motion: reduce` — при старте выключает анимации (тот же
   data-motion).
6. Доступность: тумблеры — `<button role="switch" aria-checked>`, слайдеры —
   нативные `input[type=range]` с `aria-label`, фокус-ринги видны, навигация
   с клавиатуры (Tab/Стрелки) работает.
7. Адаптив: при ширине < 900px окно на весь экран, нав-рейл превращается в
   горизонтальную полосу иконок сверху, слайдер-строки переносят подпись.

## Критерии приёмки

1. `npm install && npm run dev` поднимается без ошибок, `npm run build`
   собирается чисто (TS без `any`).
2. Внешне: тёмное стекло + зелёное свечение + аврора + сетка; при наведении
   на кнопки — блик-шиммер; активный пункт нава светится баром.
3. Все 14 модулей, все слайдеры (точные диапазоны/дефолты выше), секции
   сворачиваются, тумблеры анимированы, значения live.
4. Синхронизация: Модули ↔ HUD, Графика ↔ Test tools; localStorage переживает
   F5.
5. Окно клампится к вьюпорту, контент скроллится красивым скроллбаром,
   Test tools таскается и не теряется за краем.
6. Код полный, без заглушек «...» и TODO: каждый компонент реализован целиком.
